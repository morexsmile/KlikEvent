# KlikEvent

**Kliknij. Odkryj. Przeżyj.**  
*Click. Discover. Experience.*

KlikEvent is a modern event discovery platform designed to help people find exciting events, explore local experiences, and discover what's happening in cities across Poland.

The project combines a vibrant visual identity with an intuitive interface, making event discovery simple, engaging, and accessible.

🔗 **Live Website:** [https://morexsmile.github.io/KlikEvent/](https://morexsmile.github.io/KlikEvent/)

📂 **GitHub Repository:** [morexsmile/KlikEvent](https://github.com/morexsmile/KlikEvent)

---

## 🛠️ Technologies

The project is built using:

- **HTML5** – semantic page structure.
- **CSS3** – responsive layouts, styling, and visual effects.
- **JavaScript (Vanilla JS)** – interactive functionality and dynamic content.
- **LocalStorage** – client-side data storage where implemented.
- **Google Fonts** – DM Sans and Outfit.
- **Unsplash** – event photography.

## 🎨 Design Concept

KlikEvent follows an **Urban Energy** visual direction.

The interface combines:

- Deep navy and purple tones.
- Vibrant orange accents.
- Modern typography.
- Dynamic gradients.
- Clean event cards.
- A user-friendly navigation experience.

The goal is to create an energetic digital environment that reflects the excitement of discovering new experiences.

---

## ⚠️ Project Status

KlikEvent is a frontend portfolio project.

Event information is currently based on demonstration data. Features such as authentication, newsletter delivery, ticket reservations, and payment processing should not be considered fully operational unless connected to their respective backend services.
